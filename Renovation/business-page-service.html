What Is It?

Your business, online.

A Business Website is a customer-facing online presence. It gives customers a clear, professional place to discover your business, view what you offer, and find your contact details — at any time, from any device.

Typical content a Business Website can include:

  • Business introduction
  • Products
  • Services
  • Menu
  • Pricing
  • Gallery
  • Contact
  • Location
  • Opening hours
  • Social media
  • Inquiry / contact options

The exact content depends on your business — we agree on the structure before development starts.

Who Is It For?

Five common types of business website.

Note: A Business Website does not automatically include online payment or e-commerce checkout. Those are separate features and are quoted separately if required.

How Pages Are Counted

A page is a URL — not a product card.

Counts as ONE page

A distinct URL / content page

Each of these is one page in the package scope:

  • /  —  Home
  • /about
  • /services
  • /products
  • /contact
Does NOT count as a page

Items inside a page

These do not add to the page count:

  • A product card in a product grid
  • A menu item in a menu list
  • An image inside a gallery
  • A section within a page

What about product detail pages?

If you want individual detail pages for products — for example /products/product-01, /products/product-02 — those are additional URL pages and are quoted separately. This keeps page count and item count as two separate concepts, so there is no confusion about what is included.

Content Capacity

Page count and item count are different things.

A single Products page can display many products. A single Menu page can display an entire restaurant menu. The page is one URL — the number of items inside it is a separate question.

Starter

  • Suitable for a small amount of content
  • A single list of services or a short menu
  • Static content in HTML

Standard

  • Suitable for a larger product or menu collection
  • Content managed in JSON files for easier updates
  • Category filtering where required

We do not promise unlimited items

For static websites, product or menu data is managed through HTML, JSON or JavaScript. If you want to manage content through a browser interface instead of code, that is a data-driven approach — it is a more advanced system and is quoted separately.

Two Approaches

Static or data-driven. Two different kinds of website.

Option A

Static Business Website

Built with HTML, CSS and JavaScript. Content lives in the HTML or in JSON files.

  • Low cost, fast to load
  • Deployable to free static hosting
  • Ideal for menus, showcases and business information
  • Content updates may require code/data changes unless a management system is added
Option B

Data-Driven Business Website

For businesses that need easier content management. Uses an API or data layer, and may include a database or admin interface.

  • Product, menu and content management
  • Dynamic content and updating without code
  • More advanced infrastructure may be needed
  • This moves toward a Business System, not a simple website

Which one do you need?

If you need to update a menu, product prices or business hours occasionally, a static website is usually the right choice. If you need frequent updates, an admin login, or data management, that is a data-driven system — often closer to the POS / Business Management service than a standard Business Website.

FAQ

Common questions about business websites.

Do I need a .com domain?

No. A free hosting URL (for example, a GitHub Pages or Cloudflare Pages address) may be sufficient for some projects. A .com domain is recommended for a more professional, branded presence — but it is optional and is paid to a third-party registrar, not to Profile Craft.

Can I use GitHub Pages?

Yes, for suitable static websites. GitHub Pages is a good fit for HTML / CSS / JavaScript sites where content is stored in HTML or JSON. It is not suitable for sites that require a PHP backend or an SQL database.

Can I use Cloudflare?

Yes. Cloudflare can be used for DNS, SSL, CDN, security and static website hosting (via Cloudflare Pages) where appropriate. Whether this costs money depends on which Cloudflare services you use and how much traffic/usage the site receives. Cloudflare is not automatically free for every configuration.

Can I add products?

Yes, depending on the selected implementation and content scope. In a static website, products are typically stored in HTML or JSON files. Adding or changing products then means editing those files. If you need to add products through a browser interface without touching code, that requires a data-driven system with a backend or database — quoted separately.

Can I accept online payments?

Online payment is not automatically included in a Business Website package. It requires a payment gateway integration, which involves a backend, a database and third-party fees. If you need online payment, we will scope it as a separate, more advanced project.

Can you build a restaurant digital menu?

Yes. A restaurant menu website fits within the Business Website service. Depending on your needs, the menu can be static (HTML/JSON) or filtered by category with JavaScript. If you want to manage menu items yourself through an admin panel, that becomes a more advanced system and is quoted separately.

Is POS included?

No. POS is a separate service. A Business Website is customer-facing and shows your business. A POS is internal and lets you and your staff manage sales, orders, products, inventory and reports. If you need both, they are quoted and built as two separate projects.
